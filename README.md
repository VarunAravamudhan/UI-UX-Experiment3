# Experiment 3 – Heuristic Evaluation of an Existing Website or App

## AIM

To analyse and compare the user experience of competing websites using heuristic evaluation principles, redesign the user interface in Figma by incorporating usability improvements, and evaluate the impact of design changes on user behaviour using A/B testing methods.

## ALGORITHM

1. Select and analyse 2–3 competing websites or applications belonging to the same category.
2. Evaluate their user interfaces based on usability, navigation, consistency, accessibility and visual design.
3. Identify usability issues and areas requiring improvement in the analysed websites.
4. Create an improved user interface design using Figma by incorporating the identified design improvements.
5. Design the homepage, product sections, promotional banner, product gallery, About Us section and footer.
6. Compare the original design with the improved design using A/B testing methods to evaluate potential changes in user behaviour.
7. Present the redesigned interface using Figma frames and screenshots.
